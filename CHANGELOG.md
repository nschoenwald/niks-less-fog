# Changelog

## 14.1.1

- Removed the French, Spanish, Italian, Brazilian Portuguese, Japanese, Polish and Czech translations. They were machine-translated and never checked by a native speaker. Players who use Foundry in one of these languages now see this module in English. Translations by native speakers are welcome as an issue or pull request.

## 14.1.0

- The module is now available in German, French, Spanish, Italian, Brazilian Portuguese, Japanese, Polish and Czech.
- Setting names, hints and the GM Vision button tooltip are now translatable.

## 14.0.1

- Toggling GM Vision now takes effect immediately, even while a token is selected.

## 14.0.0

- The module is now **Nik's Less Fog** (`niks-less-fog`) and works with Foundry VTT v14. Older Foundry versions are no longer supported.
- The [libWrapper](https://foundryvtt.com/packages/lib-wrapper) module is now required.
- New setting **GM Vision Button** lets the GM show or hide the GM Vision button in the Token controls.
- Reveal Tokens no longer shows tokens that are on a different scene level.
- Reveal to All Players no longer shows tokens the GM has hidden.
- Changing Fog Opacity or Reveal to All Players now applies right away, without reloading the scene.
- Reveal Tokens now also works when the Levels module is enabled (scene levels are built into Foundry v14).
- Settings from the old `lessfog` module are not carried over. Check the module settings after switching.
